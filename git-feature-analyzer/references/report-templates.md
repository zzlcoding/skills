# 报告模板

本文件定义全局汇总报告和分支详细报告的标准结构与 Markdown 表格模板。

报告输出目录约定：`reports/git-feature-analysis/YYYY-MM-DD/`

```
reports/git-feature-analysis/YYYY-MM-DD/
├── 全局功能汇总.md
├── 功能统计.md
├── 跨分支功能关联.json
├── 分析元数据.json
└── 分支详情/
    ├── project-a.md
    ├── project-b.md
    └── ...
```

---

## 1. 全局功能汇总.md

### 1.1 必需章节

1. 仓库基本信息
2. 统计起始日期与时区
3. 分析执行时间
4. 分支覆盖情况
5. 分析范围和限制
6. 全局功能统计
7. 跨分支功能对比
8. 多项目共享功能
9. 项目独有功能
10. 需要人工确认的内容

### 1.2 模板

```markdown
# 全局功能汇总报告

## 仓库基本信息

| 项目 | 值 |
|---|---|
| 仓库路径 | `<绝对路径>` |
| 当前分支 | `<分支>` |
| 远程仓库 | `<remote URL>` |
| 工作区状态 | 干净 / 有未提交修改（详见 §分析范围和限制） |

## 统计信息

| 项目 | 值 |
|---|---|
| 统计起始日期 | `YYYY-MM-DD` |
| 统计时区 | `Asia/Shanghai` |
| 分析执行时间 | `YYYY-MM-DDTHH:MM:SS+TZ` |
| 使用模型 | `<model-id>` |
| Prompt 版本 | `vX` |

## 分支覆盖情况

| 分支 | 类型 | 基准 Commit | 当前 HEAD | 状态 |
|---|---|---|---|---|
| main | 本地+远程 | abc1234... | def5678... | 成功 |
| project-a | 本地 | ... | ... | 成功 |
| project-b | 远程 | ... | ... | 成功 |
| project-x | 本地 | ... | ... | 失败：<原因> |

> 扫描分支数量：N  
> 成功分析分支数量：M  
> 失败分支：`project-x`

## 分析范围和限制

- 统计范围：基准 Commit 与当前 HEAD 之间的代码差异。
- 时间口径：基于 Git 第一父提交策略。
- 排除目录：`build/`、`dist/`、`vendor/`、`third_party/`、`node_modules/`、`.git/`。
- 工作区状态：<说明>。
- 远程跟踪分支可能过期：<若未执行 git fetch，在此说明>。

## 全局功能统计

### 表 1：按分支 × 功能分类统计

| 分支 | 新增功能 | 功能增强 | Bug 修复 | 性能优化 | 架构调整 | 配置调整 | 功能删除 | 非功能性 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| main | 8 | 5 | 3 | 2 | 1 | 1 | 0 | 2 |
| project-a | 4 | 6 | 2 | 1 | 0 | 0 | 1 | 3 |
| ... | | | | | | | | |

### 表 2：仓库整体汇总

| 指标 | 数值 |
|---|---:|
| 分支功能记录总数 | 56 |
| 去重后唯一功能数量 | 32 |
| 多分支共享功能数量 | 18 |
| 项目独有功能数量 | 14 |
| Cherry-pick 关联功能数量 | 6 |
| 待人工确认功能数量 | 4 |

## 跨分支功能对比

### 表 3：跨分支功能关联分布

| 关联类型 | 功能数量 | 占比 |
|---|---:|---:|
| IDENTICAL（完全相同） | 12 | 37.5% |
| SAME_FEATURE（相同功能） | 4 | 12.5% |
| RELATED（相关功能） | 2 | 6.25% |
| INDEPENDENT（独立功能） | 14 | 43.75% |
| UNCERTAIN（待确认） | 0 | 0% |

### 表 4：典型跨分支关联示例

| 统一编号 | 功能名称 | 涉及分支 | 关系类型 | 置信度 |
|---|---|---|---|---:|
| U001 | 网格数据缓存机制 | main, project-a, project-b | IDENTICAL | 0.99 |
| U002 | OAuth2 登录 | main, project-c | SAME_FEATURE | 0.88 |
| U003 | 日志聚合 | project-a, project-b | RELATED | 0.82 |

## 多项目共享功能

列出跨分支 `IDENTICAL` / `SAME_FEATURE` / `RELATED` 的功能，附统一编号、涉及分支与简要描述。

| 统一编号 | 功能名称 | 涉及分支 | 关系类型 | 简要描述 |
|---|---|---|---|---|
| U001 | 网格数据缓存机制 | main, project-a, project-b | IDENTICAL | 新增网格数据缓存能力 |

## 项目独有功能

列出仅出现在某一个分支、跨分支去重后仍唯一的功能。

| 分支 | 唯一功能数 | 功能列表 |
|---|---:|---|
| project-c | 5 | U010、U012、U015、U018、U020 |
| project-d | 3 | U025、U028、U030 |

## 需要人工确认的内容

| 类型 | 项目 | 原因 |
|---|---|---|
| 分支 | `project-x` | <失败原因> |
| 分支 | `release-v1` | 起始日期之前无第一父提交，基准待人工确认 |
| 功能 | U007 | 代码与功能名称相似但接口不一致，证据不足 |
| 功能 | U011 | 仅凭 Commit Message 推断，需要确认实际行为 |

```

## 3. 分支详情/<branch>.md

每个分支一份 Markdown 文件。

### 3.1 模板

```markdown

| 当前 HEAD | `<head-sha>` |
| 当前时间 | `YYYY-MM-DDTHH:MM:SS+TZ` |
| 统计起始日期 | `YYYY-MM-DD` |
| Commit 数量（第一父） | N |
| 代码变更文件数量 | M |
| 涉及模块 | 模块A、模块B |

## 二、新增功能

| 涉及模块 | 模块A、模块B |

| 相关 Commit | `<sha>`、`<sha>` |
| 代码依据 | <证据 1>、<证据 2> |

### F002 ...
```
